Snake (C++ / raylib)

Igra Zmija za jednog igrača, izrađena u C++-u uz grafičku biblioteku raylib. Projekt je rađen na fakultetu (SOSS, Sveučilište u Splitu) u sklopu kolegija Objektno orijentirano programiranje.

Mogućnosti
  izbornik s biranjem brzine igre
  stanja igre: izbornik, igra i kraj igre
  zmija se kreće strelicama, a pojedena hrana je produljuje
  sudar sa zidom ili vlastitim repom završava igru
  hrana se nasumično pojavljuje na polju koje nije zauzeto zmijom
  bodovanje (rezultat se prikazuje ispod polja)
  grafika s teksturom jabuke i šahovskim uzorkom polja
